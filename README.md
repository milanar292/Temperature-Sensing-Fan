# Temperature Sensing Fan using Arduino

## Overview

This project automatically controls a DC fan based on the surrounding temperature using an Arduino Uno and an LM35 temperature sensor.

## Components

- Arduino Uno
- LM35 Temperature Sensor
- DC Motor (Fan)
- Transistor/Motor Driver
- LCD Display
- Jumper Wires
- Breadboard

## Working

- Reads temperature from the LM35.
- Displays the temperature on the LCD.
- Turns the fan ON when the temperature exceeds the threshold.
- Turns the fan OFF when the temperature drops below the threshold.
